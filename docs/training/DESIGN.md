# Design

Artwork approval names one revision. A later revision needs its own approval.

1. Open the job’s artwork.
2. Upload the design and make a proof. The proof is not the print file.
3. Record customer comments on that revision.
4. A change is a new revision. The approved revision stays as it was.
5. Add the production file and approve that file before anyone asks for a production release.

See `docs/ARTWORK_MANAGEMENT.md` and `docs/USER_GUIDE.md`.
