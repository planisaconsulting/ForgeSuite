# Purchasing

A purchase order is not stock. The goods receipt is what adds quantity.

1. Start from the shortage or a purchase request.
2. Send an RFQ to the suppliers you choose. One supplier does not see another supplier’s price.
3. Compare the replies. The system does not award the cheapest by itself.
4. Create the purchase order and receive what arrived, including a partial or damaged receipt.
5. Quarantine stock is not available to the job.

See `docs/PROCUREMENT.md` and `docs/USER_GUIDE.md`.
