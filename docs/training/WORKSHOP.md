# Workshop

My Work at `/work` is the list for today. A job card does not show cost unless your role may see it.

1. Open the released job. If release was blocked, do not start production from an old pack. A superseded pack is not the file to produce.
2. Scan the job, the roll, or the package into the screen the job card names.
3. Issue material from the movement ledger. A repeat of the same scan must not consume the roll twice.
4. Record waste separately from the graphic area.
5. Finish the checks the release asked for before dispatch.
