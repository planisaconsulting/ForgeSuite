# Calendar

The calendar is a view of dates that already live on installations, tasks, and the schedule. It is not a second scheduler. Phase 8 resource scheduling remains the place that plans a resource.

Open Calendar for an agenda, day, week, or month. My calendar shows work assigned to you. Company calendar needs `calendar.view_company`.

Each row links back to the job or field record. If an installation date changes on the job, the calendar shows the new date. There is no separate calendar row to drift.

Colour is not the only status cue. The status word is shown beside the date.

Reminders use the notification table. The same installation, lead time, and date produce one notice. A reminder does not promise that the work will finish that day.

External personal calendars are not written back into an installation. There is no Google or Microsoft connector in this release, and the application does not drive a consumer calendar website.
