# Operational workspace

My work still lists today’s tasks, overdue tasks, upcoming tasks, and assigned installations. Awaiting me adds expense approvals and overdue assigned tasks. Each line links to the record that owns the state. The inbox does not keep a second status.

Priority is the task priority already stored: urgent, high, normal, or low. An expense approval is normal. Nothing assigns urgency from a model.

Quick actions honour the same permissions as the pages they open. New expense, new site survey, and search sit with the existing new quote and new customer actions. Ctrl or Command K opens search when the cursor is not in a field.

Global search returns a type, number, title, context, status, and date. Invoice rows are included only when the signed-in person can view invoices. Expense numbers are matched from the start of the number, not with a leading wildcard.

Favourites are per user. Suggested saved views are “My open quotes”, “Installations this week”, and “Expenses awaiting approval”. They use the existing saved-view filters.

Job cost trace lists quoted revenue, quoted cost, material, labour, other costs with their references, mileage, and logistics. Project actual cost includes job actuals. A job expense is not added a second time as a project direct cost.
