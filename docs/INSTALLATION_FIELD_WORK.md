# Installation field work

Installation stays on `job_installations`. Phase 8 adds planned, confirmed, travelling, on site, in progress, blocked, partially complete, complete pending sign-off, signed off, snagged, and cancelled. The older statuses still work.

The installation pack shows the customer, site, contact, artwork titles, checklist, and access notes. It does not include margin, gross profit, debt, or supplier cost.

Lightbox and vehicle checklists are separate templates. They are not copied onto every installation. Arrival stores one optional location from that action. Start stores the server time and can keep a device time beside it.

Photos use the existing field photo table with categories before, during, after, detail, problem, and sign-off.

A snag records a type and a severity of minor, major, or blocking. The source is a category, not a finding of fault. A blocking snag stops sign-off and does not complete the job.

Sign-off stores the name, role, statement version, and time. A completion certificate is allowed only after sign-off and only when no blocking snag is open. An eligible installed product can become a customer asset through the existing asset workflow. The installation does not create one by itself.
