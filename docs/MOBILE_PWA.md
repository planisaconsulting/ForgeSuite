# Mobile and PWA

Install from Chrome on Android with Install app, or from the browser menu. On iPhone use Share, then Add to Home Screen. The manifest name is Sign-Forge, display is standalone, and the icons are the 192 and 512 PNG files. Some camera and background behaviour differs on Safari.

The service worker cache is `signforge-shell-v3`. It holds CSS, JavaScript, icons, and the offline page. It does not cache signed-in HTML or API responses.

Download a field pack before leaving coverage. The pack is the job, survey, delivery, or installation in front of the person. It omits cost and margin. Offline drafts can include measurements, notes, photos, checklist answers, snags, signatures, delivery exceptions, arrival, time, mileage, and a draft expense with a receipt. Pricing, invoices, payments, stock issues, dispatch confirmation, contractor approval, cost approval, expense approval, job completion, and other approvals stay online. A signature captured offline keeps the device time and receives a server time when it syncs.

Sync sends a few operations at a time. The server checks permission and version again. The same operation id does not create a second photo, signature, or proof of delivery. If the office and the phone both edit the same installation notes, the conflict screen shows both texts. A photo can still sync when the office only moved a date. A new artwork revision marks the pack stale and blocks completion until the pack is refreshed.

GPS is requested only for travel, arrival, signature, and completion. Denying it continues when the policy is optional. There is no route tracking.

Revoke a lost device from Devices. The next sync is refused.

An Android package, if you add one later, should wrap this site. Do not keep a second copy of the rules.
